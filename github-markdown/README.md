# Desafio de Git e Github - DIO (Github e MarkDown)

Resolução do desafio de sobre markdown e uso do github para colaboração proposto pela Digital Innovation One (DIO). Reforçando o uso de comandos básicos do git e manuseio de repositórios remotos com Github.

## 🚀 Sobre o Projeto
O objetivo do desafio foi praticar comandos básicos do Git e coloborar com outros devs. O projeto foca no trabalho em equipe e versionamento de código.

### 💻 Tecnlogias e Conceitos
- **Ferramentas:** Git e GitHub para versionamento de código e colaboração em equipe

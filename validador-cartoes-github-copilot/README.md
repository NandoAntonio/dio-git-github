# Validador de bandeira de cartões

Projeto desenvolvido como desafio proposto pela **DIO (Digital Innovation One)** de Git, GitHub e GitHub Copilot. A aplicação recebe um número de cartão, identifica sua bandeira por meio dos prefixos cadastrados e verifica se o número possui uma estrutura válida.

### 💻 Tecnologias utilizadas

- **Linguagens:** JavaScript
- **Estrutura:** Manipulação de números e funções;
- **Ferramentas:** 
- Node.js: executar código JavaScript fora do navegador
- Markdown: para documentação e cadastro das regras de identificação
- Git e GitHub: para versionamento do projeto
- Algoritmo de Luhn, para validação matemática do número do cartão
- GitHub Copilot: Assistente de IA para desenvolvimento e aprimoramento de códigos
